# 単語データ作成・検証 Skill

## パターンA: 新規生成
1. 対象レベル・語数・教材名(unit)をユーザーに確認(不明なら difficulty 1〜30 に分散、unit は聞く)。
2. `ops/prompts/word-list-generator.md` のルールに従いTSVを生成し、一時ファイルに保存。
   特に「同一リスト内で意味が紛らわしい訳語を避ける」「meaning重複禁止」を厳守(4択の正誤判定が壊れる)。
3. 検証: `node ops/scripts/validate-words.mjs <file> --out <clean.tsv>` — エラー0件になるまで修正。
4. 納品: クリーンTSVのパスと、先頭10行のプレビューを提示。「Wordsシート(共有)または管理者ページの貼り付け欄へコピーし、投入後に1回プレイして確認」と案内。

## パターンB: 既存データの検証
1. ユーザーのファイル(TSV/CSV)を `validate-words.mjs` にかける。
2. エラー・警告を日本語で要約し、修正版TSVを出力する。列ずれ警告(wordに日本語/meaningが英字)は目視確認を促す。

## 注意
- 訳語の質はスクリプトでは検証できない。生成した場合は必ず「多義語・紛らわしい訳語の目視チェック」をユーザーに依頼する。
- 共有Wordsシートへの書き込みはユーザーが行う(Claudeはシートを直接触らない)。
