# AdSense導入 準備チェックリスト

審査申請の前に、上から順に全部埋めること。**申請・アカウント作成・支払い設定は必ず人間が行う。**

## 1. コンテンツ・ページ要件
- [ ] プライバシーポリシーを公開した(`privacy.html`。下書き: `ops/monetization/privacy-policy.html`)
- [ ] 運営者情報(連絡先メールアドレス)をページに記載した
- [ ] 利用規約(禁止事項バナーの内容を整理して1ページに)を公開した
- [ ] サイトに十分なコンテンツがある(トップ+使い方説明ページを追加すると審査に通りやすい)

## 2. 技術要件
- [ ] 独自ドメインを取得した(github.io のままでは審査に通りにくい。年1,000円台)※課金発生=人間判断
- [ ] GitHub Pagesにカスタムドメインを設定した(リポジトリ Settings → Pages → Custom domain)
- [ ] HTTPSで表示できることを確認した

## 3. 未成年利用者への配慮(必須)
- [ ] AdSenseの「子ども向けコンテンツ」設定を確認し、必要ならタグ付けした
- [ ] パーソナライズ広告を無効化する設定を検討した(単価は下がるが安全)
- [ ] 授業中に使う端末で広告が出ることを学校側が問題にしないか確認した

## 4. 実装(審査通過後)
- [ ] `index.html` の `#sponsorSlot`(結果画面のスポンサー枠)にAdSenseコードを貼る
      ※クイズ回答中の画面には広告を入れない(誤クリック誘発=ポリシー違反リスク)
- [ ] 広告表示後にスモークテスト(`node ops/scripts/smoke-test.mjs`)+実機確認
- [ ] クリック率・収益をAdSense管理画面で週次確認

## 5. やってはいけないこと
- 自分や生徒に広告をクリックさせる(アカウント停止になる)
- 挑戦回数の回復を広告視聴と引き換えにする実装をAdSense(Web)でやる(リワードはAdMob=アプリ版の機能。Webでは不可)
- 生徒の個人情報(クラス・出席番号・ニックネーム)を広告ネットワークに渡す実装
