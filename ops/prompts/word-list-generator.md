# 単語リスト生成プロンプト(コピペ用)

用途: Claude(このリポジトリのセッション、またはclaude.ai)に貼ると、
アプリにそのまま投入できる形式のTSV単語データを生成させられる。

## プロンプト本文(【】を埋めて使う)

```
英単語学習アプリ用の単語データをTSV形式で作ってください。

対象: 【例: 高校1年生 / 英検準2級レベル / ターゲット1900の801〜900番相当】
語数: 【例: 100語】
教材名(unit列の値): 【例: ターゲット1900-5】

形式(1行目はこのヘッダー、以降タブ区切り):
word	meaning	difficulty	unit	enabled

ルール:
- word: 英単語(小文字。固有名詞は除く)
- meaning: 日本語の意味。簡潔に(10文字以内目安)。選択肢として表示されるので、
  同じリスト内で意味が紛らわしい単語同士(例: 「重要な」と「重大な」)は避ける
- difficulty: 1〜30の整数。易しい語=1、難しい語=30。指定レベル内で分散させる
- unit: 上記の教材名で統一
- enabled: すべてTRUE
- 重複禁止。meaning が同一の行も禁止(4択の正誤判定が壊れるため)
```

## 生成後の必須手順(ここを飛ばさない)

1. 出力をファイルに保存(例: `new-words.tsv`)
2. 検証にかける:
   ```
   node ops/scripts/validate-words.mjs new-words.tsv --out clean-words.tsv
   ```
3. エラー0件を確認してから、`clean-words.tsv` の中身を目視で10行サンプルチェック
   (訳語の質はAI任せにしない。特に多義語)
4. Wordsシート(共有)に貼り付け、または管理者ページの「端末内単語データ」欄に貼って動作確認
5. 本番投入後、自分で1回プレイして4択が正常か確認
