# シーズン切替チェックリスト

所要時間: 15分(旧手順は30分+事故リスク)。上から順に。

## 切替前
- [ ] 管理者ページ →「共有データをバックアップ」でCSVを保存した(**最重要。飛ばさない**)
- [ ] バックアップCSVをGoogle Driveの `vocab-battle/backups/YYYY-MM-DD/` に保存した
- [ ] 新シーズンのID(例: `snow_season`)と表示名(例: `Snow Season`)を決めた
- [ ] 新バナー画像を用意した場合は `assets/` に追加した(なければ据え置きでOK)

## 切替
- [ ] dry-runで差分確認: `node ops/scripts/switch-season.mjs --id <ID> --name "<名前>"`
- [ ] 差分が正しいことを確認して `--apply` 付きで再実行
- [ ] GAS/スプレッドシート側のシーズン設定(Settingsシート等)を新シーズンに更新
- [ ] 挑戦回数の設定(1日◯回)を今シーズンの方針に合わせて確認

## リリース
- [ ] `node ops/scripts/smoke-test.mjs` が全項目OK
- [ ] `git diff` で意図した変更だけであることを確認
- [ ] commit & push(またはWeb UIでアップロード)
- [ ] 本番URLをスーパーリロード(Ctrl+Shift+R)して新シーズン名が表示される
- [ ] 本番で1回プレイし、戦闘力1000スタート・ランキングが新シーズンになっている

## 事後
- [ ] 生徒への告知(新シーズン開始のお知らせ)
- [ ] 旧シーズンの結果(TOP10など)を記録に残す(B2B営業の実績データになる)
