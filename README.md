# vocab-battle（英単語バトルレート）

高校英語の生徒向け単語学習 Web アプリ。英単語クイズの成績でレートを競い、シーズン制のランキングを表示します。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体（生徒タブ／管理者タブ） |
| `app.js` | アプリ全体のロジック |
| `review.js` | 解答レビュー画面 |
| `styles.css` | スタイル |
| `assets/` | シーズンバナー等の画像 |

バックエンドは Google Apps Script（GAS）の WebApp です。単語データ・ランキング・試行回数の管理は GAS 側のスプレッドシートで行います。

## 公開・利用方法

1. このリポジトリのファイルを静的ホスティング（GitHub Pages 等）に配置する
2. 管理者タブで GAS WebApp の URL を設定する
3. 生徒はクラス・出席番号・ニックネーム・暗証番号を登録して利用する
